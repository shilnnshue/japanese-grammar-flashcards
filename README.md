# 日语 N1/N2 级必备语法 368 句 · 闪卡

把《笔记本日语1·2级必备语法368句》做成了一个**单文件 HTML 闪卡应用**，用来「根据句子背语法」。完全离线、双击即用。

## 功能

- **卡片正面**：日文例句（大字）+ 中文翻译 + 一行语法提示（句型 / 接続）
- **卡片背面**：中文释义 + 接続公式 + 句型
- **语音朗读**：点 🔊 或按 `S` 朗读例句；默认走 Google 自然日语语音，可切本机嗓音，离线自动回退
- **筛选 / 搜索**：按级别（1级/2级）、分类、单元筛选，支持搜索句型或释义
- **记忆追踪**：`认识`(K) / `不认识`(J) 标记，本地保存，可只刷「未掌握」
- **打乱 / 重置 / 进度条**：认识 · 不认识 · 未学 · 完成度一目了然

## 数据说明

源 Excel 只有 `句型 / 接続 / 释义` 三列，本身**没有例句**。这里的**例句由 AI 生成**（卡片内已标注「AI生成·请核对」），作为学习参考，考试前建议自行过一遍准确性。

## 文件

| 文件 | 说明 |
| --- | --- |
| `日语语法闪卡.html` | 成品应用（已内嵌全部 368 条数据，直接打开即可） |
| `grammar_data.json` | 从 Excel 提取的结构化数据（句型/接続/释义/级别/分类） |
| `examples.json` | 每条句型对应的 AI 生成例句（日文+中文） |
| `finalize.py` | 合并数据并注入 HTML 的构建脚本 |

## 使用

直接双击 `日语语法闪卡.html` 即可（推荐 Chrome / Edge）。无需安装、无需联网（联网时语音更自然）。
