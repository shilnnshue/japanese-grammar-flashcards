日语语法闪卡 · 完整使用说明

JLPT N1/N2 句型语法 368 句 · 本地真人级语音（微软 Nanami）· 支持多选筛选

一句话上手：打开页面 → 点卡片（或按 空格）翻面看语法点 → 点卡片听发音 → 用左侧「级别 / 分类 / 单元」下拉可同时勾多个做并集筛选。进度自动保存在本机浏览器。

一、怎么打开这个应用

① 线上版（随时访问，推荐）

直接用浏览器打开：https://shilnnshue.github.io/japanese-grammar-flashcards/

所有语音文件已随页面一起部署，无需下载，首次加载稍慢（约 13MB 语音）。建议用 Ctrl+Shift+R 硬刷新以清掉旧缓存。

② 本地版（离线、最稳）

文件夹 自然语音版/ 里有一个 日语语法闪卡.html 和同级的 audio/ 文件夹。

⚠️ 关键：HTML 文件和 audio 文件夹必须放在一起打开！如果只把 HTML 单独拷走，相对路径断了，就会找不到语音文件。整文件夹一起拷贝即可离线使用。

二、卡片怎么用

正面（默认）

  • 例句日文（重要语法词已用高亮标出，方便定位句型）
  • 例句中文翻译
  • 句型 + 接続（接续）提示，如「动词·原形」
  • 左上角徽章：#编号 · 级别 · 单元 · 分类

反面（点卡片 / 空格翻面）

  • 语法词（日文，大字）——翻到这一面时，发音播放的是单词而非例句
  • 中文释义（小字）
  • 接続 与完整句型

三、发音（真人级自然语音）

发音使用微软 Edge 神经语音 ja-JP-NanamiNeural（真人级女声），已离线合成好 368 句例句 + 368 个单词的 MP3。

  • 点卡片：朗读当前面——正面读例句，反面读单词。
  • 按 S：随时重新朗读当前内容。
  • 🔊 自动朗读：勾选后，翻面 / 切换卡片会自动朗读。
  • 例句的音频在 audio/001.mp3 …，单词音频在 audio/w/001.mp3 …，按卡片编号一一对应。
已彻底移除机械音：本应用不再使用任何系统机械音或联网云端语音作为退路，发音只有这一套本地 Nanami 真人语音，永远不会退化成机械音。

四、筛选 本次新增：支持多选

工具栏第一组有三个下拉（点开后是复选框）：

  • 级别：1级 / 2级
  • 分类：目的、原因·理由、逆接、时间、假定、例示……（共 42 类）
  • 单元：按教材单元（共 26 个）

现在可以同时勾选多个，表示「或」的并集关系：

  • 勾「1级」→ 只看 121 句 1级语法；
  • 再勾「2级」→ 同时看 1级 + 2级（并集）；
  • 分类里勾「目的」+「原因·理由」→ 同时练这两类。

什么都不勾 = 不过滤（显示全部 368 句）。下拉标题会实时显示当前选择，例如「级别：1级·2级」。

✕ 清空筛选 按钮：一键取消所有勾选，回到全部 368 句。

五、模式 & 搜索

模式（下拉）

  • 全部：按编号顺序
  • 复习（未掌握）：只看还没标「认识」的卡片（不认识 + 未学，适合集中复习薄弱点）
  • 仅已掌握：只看已标「认识」的（用于快速回顾）
  • 随机：打乱顺序

🔀 打乱顺序 按钮：对当前筛选结果立即随机重排。

搜索

顶部搜索框可搜句型 / 中文释义 / 例句日文 / 例句中文 / 接続或卡片编号，边输入边过滤；清空关键词即恢复。

六、进度与掌握度（两级标记）

每张卡有两种状态，可随时切换：

  • 按 K 标记「✓ 认识」= 已掌握（彻底会了，可暂时搁置）。
  • 按 J 标记「✗ 不认识」= 还没记住，需要多练。

标了「认识」的卡片，正面左上角会出现绿色 ✓ 已掌握 徽章、卡片外圈也变绿，一眼就能区分。

顶部「完成度 %」按 认识 / 总数 计算；顶部数字分别统计 认识 / 不认识 / 未学。

  • 所有标记自动保存在本机浏览器（localStorage），关掉网页再打开还在。
  • ↺ 重置进度：清空所有标记，重新开始。

📋 列表视图（一目查看）

顶部「🃏 闪卡 / 📋 列表」可切换视图。列表视图把当前筛选结果列成清单，每项只显示「句型 + 意思」，并用圆点标注状态（● 认识、● 不认识、● 未学）。

  • 顶部 全部 / 认识 / 不认识 / 未学 四个标签可快速只看某一类。
  • 点任意一项会跳回闪卡视图，打开那张卡的完整详情（例句 / 单词 / 释义 / 接续）。
注意：进度是按浏览器 + 设备保存的。换浏览器 / 换电脑 / 清缓存会丢失进度；线上版和本地版的进度不互通。

九、常见问题（FAQ）

Q1：发音变成机械音 / 没声音了？

本应用已移除机械音退路，正常只会是 Nanami 真人音。若出现没声音：① 线上版请 Ctrl+Shift+R 硬刷新；② 本地版请确认 audio/ 文件夹和 HTML 在一起；③ 浏览器可能禁用了声音，点一下卡片或页面任意处再试。

Q2：筛选后卡片全没了？

可能你勾了「复习（未掌握）」模式，而当前筛选下的卡片都已标「认识」——这是正常设计（已掌握的会被排除）。点「✕ 清空筛选」或切回「全部」模式即可。

Q3：为什么勾「1级+2级」是 367 条而不是 368？

368 句里有 1 句未标注级别，按级别筛选时它会被排除，所以 1级(121)+2级(246)=367 是正确结果。

Q4：进度能同步 / 导出吗？

当前进度仅存本机浏览器，不联网、不跨设备。如需换设备，请在旧设备导出书签式备份或重新标记。
